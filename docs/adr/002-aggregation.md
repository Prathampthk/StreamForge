# ADR 002: separate minute aggregate states (accepted foundation)

Use append MergeTree facts and separate AggregatingMergeTree revenue/traffic state tables fed by incremental materialized views. Revenue includes currency; traffic must not be duplicated across currency groups. Explicit merge functions give correct results before background merges. SummingMergeTree is simpler for additive columns but requires careful sum queries and cannot directly express general aggregate states; raw scans are simpler but increase query work. ReplacingMergeTree offers eventual replacement only and cannot retract view contributions. The insert-trigger design is fast but repeats duplicate contributions and does not reflect later source deletes. Tests verify arithmetic, not sink idempotency. This foundation may change after the dedup ADR is resolved.
